# Change Log

All notable changes to the "dark-green-power" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.3.0] - 2026-07-26

- Readability pass for some tokens and UI parts - improved the terminal.
- Better selection colors.
- Previously the palette was kinda bleak and misty, but now it has more contrast to it.

## [0.2.0] - 2026-07-26

- Full workbench color coverage for current VS Code: 642 new color keys (quick input, settings editor, testing, notebooks, chat / inline chat / inline edit, sticky scroll, command center, banner, bracket-pair guides, inlay hints, ghost text, SCM graph, symbol icons, keybinding labels, welcome page, charts, gauges, merge editor, and more).
- Enabled `semanticHighlighting` (semantic tokens map through the existing token colors).

## [0.1.0] - 2021-05-26

- Color adjustments.

## [0.0.1] - 2021-05-13

- Initial release
